# Логика по режимам

Координаты даны в кадре 1280x720. Во все режимы ведёт один путь: замок → `Battle` → карусель Game Modes.
Плитку ищите OCR по названию в полосе y 100–170. Свайпайте примерно на 400 px и медленно:
длинные свайпы проскакивают плитки.

**Во всех боях:** Auto включён и скорость x2 (тапать только то, что выключено). Бой дольше 30 мин считается
проигрышем: пауза → `End Battle` → подтвердить, идти дальше. Бой на паузе (`Paused` + `Continue`) → Continue.

## Classic Arena

1. При входе нажать `Refresh List` (1132,158), если он не на кулдауне. На кулдауне шаблон кнопки не совпадает.
2. В списке найти шаблоном все кнопки `Battle` и под каждой прочитать OCR мощь соперника (Team Power).
3. Бить только соперников слабее порога (у меня 700K при своей команде ~370K). Если проиграл,
   этого соперника (по мощи) не трогать 20 мин.
4. Подходящих нет → свайп списка (x=640, 640→300) и **подождать 2,5 с** (инерция).
   Конец списка → Refresh List (доступен раз в ~10 мин).
5. Prep → `Start` (~1120,653) → бой → `TAP TO CONTINUE` (640,662) → `RETURN TO ARENA`.
6. Токены 0/10 → всё равно нажать Battle. Попап «TOKENS x5 + Confirm» или «REFILL + мешок x1 + Confirm»
   (без цены) бесплатный → подтвердить. «40 Get and Use» стоит гемы → закрыть.
7. Токены восстанавливаются по 1 в час, поэтому арену стоит включать в каждый запуск.

## Clan Boss (Demon Lord)

- В правой колонке — сложности (колонка прокручивается), сундук на строке x≈1222. Красная точка = есть
  награда → `CLAIM` (640,603), повторить для каждого сундука.
- Prep: галочки Quick Battle и Start on Auto, затем `Start`. Результат приходит сразу
  («1.51B Damage Dealt» + `CONTINUE`).
- **Уже бил сегодня?** Ключам не верить: ключ, потраченный перед ресетом, засчитывается за вчера.
  Искать **свой ник** в левой таблице урона этой сложности.
- День КБ не совпадает с календарным: ресет идёт по времени клана (таймер «Time remaining» на экране босса).

## Doom Tower

- В шапке: золотые ключи `x/10` (этажи и боссы) и серебряные (секретные комнаты). Текущий этаж отмечен
  скрещёнными мечами (шаблон).
- Этаж → галочка «Start Background Auto-Climb» → дальше фоном, ~1 мин на этаж, до босса. Когда закончил —
  тап по карте → `Results` (**обязательно**, иначе башня заблокирована) → X.
- Босс — отдельным боем. Карточка с уровнем (Hard ≥ 100, Normal 50–99). Босс 120 этажа стоит вверху
  по центру, заголовок у него «Final Boss».
- Повторный бой с уже побеждённым боссом — это реплей, ключ уходит впустую. Храните побеждённых по
  заголовку prep («Floor 40: Eternal Dragon») и последний этаж в state: уровни у боссов совпадают.
- Карта скользит. Сначала смотрите, что уже видно; тяните коротко и только если босса не видно.
- **Окно «Background battle in progress» — только X, никогда End/Stop.**
- Секретные комнаты SR1…SR12 слева, SRn открывается после этажа 10n−5. Серебряный ключ тратится
  только при победе. У комнаты есть правило («Epic DEF Champions only»), список героев уже отфильтрован —
  заполнить пустые слоты первыми героями. 1 попытка на комнату за запуск.
- Hard пройден → выпадающий список сложности внизу слева (открывается вверх) → Normal. При ротации
  башни («Resets in: 1w 5d») состояние обнулить.

## Iron Twins

Нужный этап → **Background** Multi-Battle, обе галочки «Use Gems…» выключены. Пока на строке написано
«Stop Background Battle», её не трогать — ждать `Results`.

## Market

Купить Mystery Shard за 5000 серебра; карточки листаются вправо. Если шарда нет — самый дешёвый товар
до 10000 серебра: квесту нужна любая покупка (+5 токенов арены). Рынок обновляется раз в час, поэтому
пробовать перед каждой ареной, пока квест не забран. Никогда не жать «Refresh Now» за гемы.

## Live Arena

- Открыта 4 раза по 4 часа в сутки: **00–04, 06–10, 12–16, 18–22 UTC** (кнопка `Schedule` в игре).
  Закрыта → пропустить.
- `Find Opponent` → драфт: фаза 1 пик (60 с на ход) → фаза 2 бан (30 с) → фаза 3 лидер → бой.
  Каждый шаг завершается `Confirm` (1120,652).
- Драфт идёт по тегу: кнопка с мечами (67,505) открывает сохранённую в игре группу из 10 героев.
  Портреты героев — шаблоны (совпадение ≥ 0.75). План: на каждый слот основной герой и запасной.
  Если основного забрал соперник, он в списке серый с ⊘.
- В бою `Auto` (68,657) надо нажать вручную: это единственный режим, где он выключен на старте.
- Квест 5/5 → мешок → при 0/5 бесплатный рефилл (мешок x1 + Confirm). Никогда не жать `+` у токенов.

## Cursed City

Battle → Cursed City, 8 ключей в день. Открытый этап обведён бледно-голубой рамкой на карте, зелёная галка
означает «пройден». Список героев уже отфильтрован по условиям этапа → заполнить пустые слоты первыми
(порядок идёт по колонкам), затем `Start` (область справа внизу, не текст «Start on Auto»). Проигранный этап
не повторять до ресета. Исключить боссов, которых ваша команда не бьёт: у меня это Frost Spider, он
воскресает, и его карточка пропускается по шаблону. Hard закончился → Normal.

## Grim Forest (самое сложное)

- Карта шире экрана. Доступные узлы обведены бледно-бирюзовой рамкой (HSV ~93/159/254, линии пути
  насыщеннее). Маленький шестиугольник со следами — это шаг (1 энергия, без боя), крупная карточка —
  этап, сундук или алтарь. Узлы с золотой или красной рамкой закрыты.
- Карту обходить экран за экраном. Сдвиг камеры мерить по картинке (ORB), а не по длине свайпа:
  свайпы скользят. Полная карта есть в интернете: геометрия одна и та же, меняется содержимое узлов.
- Порядок на текущем экране: шаги и сундуки → золотые щиты этапов → слабые карточки (уровень ниже порога)
  → боссы последними. Порог растёт с уровнем отряда (Squad Progress Level).
- Пропущенные и проигранные узлы запоминать **по виду** (кроп, совпадение ≥ 0.9), а не по координатам:
  камера двигается.
- Команда: `Draw Champions` → `Confirm` → список выпавших героев; первый тапнутый становится лидером.
  Нужен свой список приоритета героев (шаблоны карточек, ≥ 0.88). Герои с заморозкой и окаменением
  затягивают обычные этапы — брать их только на боссов. Хилящихся боссов (Mimic и т.п.) бить только с героем
  на антихил.
- Энергия 0/30 → сразу выходить. Окна поверх карты (Squad Progress, Trait Cards, Curio Chest `COLLECT`)
  закрывать до поиска узлов.

## Мелочи

- **Guardian Ring**: Sparring Pit → баннер «Level Ready» → бесплатная кнопка «Upgrade / to Lvl. N».
  Никогда не «350 Upgrade» за гемы: тапать только кнопки с «to Lvl» и без числа над ними.
- **Quests**: замок → `Quests` → Advanced → CLAIM ALL → Daily → CLAIM ALL.
- **Playtime**: часы в замке (1187,565) → `Claim All`; держать игру открытой и возвращаться,
  пока не взята награда за 180 мин.
