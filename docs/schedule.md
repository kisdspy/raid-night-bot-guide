# Расписание, перезапуски, отчёт

Ночью всё запускает один shell-скрипт по расписанию. Сам Python-бот про расписание ничего не знает.

1. **Расписание** (Mac): launchd-агент с `StartCalendarInterval` плюс
   `sudo pmset repeat wakeorpoweron MTWRFSU <время − 5 мин>`, чтобы Mac проснулся. Крышка открыта,
   зарядка подключена, на время работы — `caffeinate -ims`. На Windows то же делает Планировщик заданий
   с галочкой «Выводить из спящего режима».
2. **Ночной скрипт**: открыть BlueStacks → `python daily.py --launch --hours N` → закрыть BlueStacks
   (`pkill -TERM`: обычный quit спрашивает подтверждение).
3. **Перезапуск**: если бот упал (код ≠ 0), убить эмулятор, подождать 20 с и запустить снова
   на оставшееся время. Максимум 2 раза и не тогда, когда осталось меньше 10 мин. Задачи сами пропускают
   сделанное (state.json), так что повтор безопасен.
4. **Запуск игры**: дождаться `sys.boot_completed`, потом `monkey -p com.plarium.raidlegends`. Первые 3 минуты
   незнакомые экраны считаются загрузкой, Back не жать.
5. **Отчёт**: каждая задача пишет строку («Арена: 9 боёв, 8 побед», «Башня: этажей 9, боссов 1»).
   Из строк и скриншотов ночи собирается HTML-страница с плитками по режимам, утром она открывается сама.
   Скриншоты незнакомых экранов — главный материал для правок.

Пример ночного скрипта (macOS):

```bash
#!/bin/bash
cd "$(dirname "$0")"
HOURS="${1:-5}"
END=$(( $(date +%s) + ${HOURS%.*} * 3600 ))
for try in 0 1 2; do
  LEFT=$(( END - $(date +%s) ))
  [ $LEFT -lt 600 ] && break
  open -a BlueStacks
  caffeinate -ims .venv/bin/python daily.py --launch --hours "$(awk -v s=$LEFT 'BEGIN{printf "%.2f", s/3600}')"
  CODE=$?
  pkill -TERM -f "BlueStacks.app/Contents/MacOS/BlueStacks"
  [ $CODE -eq 0 ] && break
  sleep 20
done
```

## Мой цикл доработки

Утром читаю отчёт → отдаю LLM лог и скриншот места, где бот ошибся → правка, скриншот уходит в selftest →
следующая ночь. Все правила и уроки я держу в одном файле для LLM (`CLAUDE.md`), чтобы она не забывала
их между сессиями. Советую делать так же.
