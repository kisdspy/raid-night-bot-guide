# Архитектура

Всё держится на одном цикле: **скриншот → какой это экран → действие для этого экрана → снова скриншот**.
Бот не написан как сценарий «нажми А, подожди 5 с, нажми Б»: в игре постоянно вылезают окна,
и такой сценарий ломается сразу. Цикл «что на экране?» сам восстанавливается после любой неожиданности.

![Главный цикл](loop.png)

## Распознавание экрана

- **Сначала шаблоны** (быстро и надёжно): кропы кнопок `TAP TO CONTINUE`, `RETURN TO ARENA`, `Start`,
  `Auto`, крестика закрытия, `Battle` в списке.
- **Потом OCR** (медленнее), только если шаблоны ничего не нашли. Замок узнаётся по словам `Battle` + `Shop`
  внизу справа, карта арен — по `Classic Arena` + `Live Arena`, попапы — по словам в них.
- **Числа** (токены `7/10`, Team Power соперника, уровень босса) читаются OCR из маленького кропа,
  увеличенного в 2–3 раза, и проверяются на правдоподобие: мощь вне 10K…20M = «не прочиталось».

## Защита от застревания

- Незнакомый экран дольше 20 с → сохранить скриншот в `logs/` и нажать ADB Back (Esc).
  В Raid Back закрывает почти любое окно.
- 3 минуты на месте → остановить задачу и перейти к следующей.
- Raid не на переднем плане (вылез магазин BlueStacks, игра упала) → заново запустить через `monkey`.
- Пустой скриншот → `adb disconnect/connect` и повтор (до ~2 мин).
- Таймаут на каждую команду adb: один зависший `input keyevent` у меня однажды уронил всю ночь.

## Состояние между запусками

Оно хранится в `logs/state.json`: что уже сделано сегодня, последний пройденный этаж башни,
побеждённые боссы, проигранные этапы, даты ресетов. Без этого бот повторяет одно и то же,
а повторный запуск после падения тратит ключи заново.

## Самопроверка (`--selftest`)

Это папка со скриншотами всех известных экранов и ожидаемым ответом для каждого. После любой правки
она прогоняется за секунды, игра для этого не нужна. Заведите её с первого дня: каждый скриншот,
на котором бот ошибся, отправляйте туда же.

## Структура моего кода

| Файл | Что делает |
| --- | --- |
| `arena.py` | `Device` (ADB), `OCR`, `Templates`, `detect()`, класс `Bot` с обработчиками `on_<state>`: Classic Arena |
| `daily.py` | `Daily(Bot)`: вся ночь по задачам (`--tasks cb,dt,arena,...`), переходы между режимами, state.json |
| `live_arena.py` | драфт и бой Live Arena |
| `grim_forest.py` | поиск узлов на карте, выбор команды |
| `cursed_city.py` | этапы Cursed City |
| `report_html.py` | HTML-отчёт за день |
| `nightly.sh` | запуск эмулятора, бота и перезапуски |
| `install-schedule.sh` | launchd + пробуждение Mac |
| `templates/` | кропы кнопок и героев (1280x720) |
| `selftest/` | скриншоты для самопроверки |
